One line: a software patch note for a bug in real life.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
v2.4.1 — Fixed a bug where Mondays loaded before the weekend had finished saving. Added a loading screen and a small apology.
```
